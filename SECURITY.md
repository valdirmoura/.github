# Security Policy

## Supported Versions

Security updates will be applied to the latest version of the repository when necessary.

| Version | Supported |
| ------- | --------- |
| latest  | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately.

Please do not open a public issue for security vulnerabilities.

You can contact me through:

- GitHub: @valdirfmoura
- Email: valdirfmoura@gmail.com

When reporting a vulnerability, please include:

- a clear description of the issue;
- steps to reproduce the problem;
- possible impact;
- affected files, dependencies, or versions, if known;
- any suggested fix, if available.

## Response

I will review reported vulnerabilities as soon as possible.

Response and correction times may vary depending on the complexity of the issue and project priority.

## Scope

This policy applies only to this repository.

Issues related to third-party packages, services, APIs, or platforms should also be reported to the maintainers of those projects when applicable.

## Responsible Disclosure

Please give me reasonable time to analyze and fix the vulnerability before publicly disclosing details.
